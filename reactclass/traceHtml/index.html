Common Mistakes

AVOID THESE
❌ Wrong
if (input == "yes") { ... }
✅ Right
if ("yes".equals(input)) { ... }
== compares addresses. Two "yes" objects at different addresses are NOT ==.
❌ Wrong
name.toUpperCase(); // does nothing
✅ Right
name = name.toUpperCase();
Strings are immutable. Methods return new objects — must reassign.
❌ Wrong
s.charAt(0) == "H" // char vs String
✅ Right
s.charAt(0) == 'H' // use single quotes for char
charAt() returns a char primitive, not a String object.
❌ Wrong
for(...) result += i; // O(n²)
✅ Right
StringBuilder sb; sb.append(i); // O(n)
String + in a loop creates a new object every iteration.
